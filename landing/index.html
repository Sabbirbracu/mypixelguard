FAQ

Questions you might have

Does MyPixelGuard upload my photos?

No. Everything runs on your device. The app contains no network code and works offline.

Will it change my original image?

Never. Cleaned and redacted images are saved as new copies in a folder you choose, and existing files are never overwritten.

Can it remove AI watermarks like SynthID?

No. It removes metadata labels such as C2PA Content Credentials and AI tags in XMP/IPTC, but it can't remove invisible watermarks woven into the pixels.

What is C2PA / Content Credentials?

A signed record embedded in an image that describes how it was made or edited. Platforms like Facebook and Instagram can read it to add labels. MyPixelGuard shows it and, with your confirmation, removes it.

Which formats are supported?

JPEG, PNG and TIFF everywhere. On Mac you can read and write HEIC, and WebP where supported. On Windows HEIC can be read (when Windows has the codec) but not written.

Does removing the background reduce quality?

No. MyPixelGuard only adds a transparency layer — the subject’s pixel colours and resolution are never changed, and PNG or TIFF are saved with no compression loss. How well the subject is detected depends on the photo, so check the preview before you save.

How accurate is the automatic detection?

Good, but not perfect: it can miss information or mark the wrong area. That's why you can review every numbered region and see an exact preview before you export.

Which computers does it run on?

Macs running macOS 13 or later. A Windows 10/11 (64-bit) version is coming soon. On Mac, Remove Background needs macOS 14.

Which languages are available?

English and বাংলা. Switch any time in Settings.
